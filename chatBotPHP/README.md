# NOTBot – Nordic Optical Telescope AI Assistant

A conversational Q&A assistant for observers and staff at the Nordic Optical Telescope.
Ask anything about NOT instruments, observing procedures, data handling, or site logistics.

## Quick Start

1. Type your question in the input area and click **Ask** (or press `Ctrl/⌘ + Enter`)
2. View sources by expanding the "X source(s)" section under each answer
3. Rate answers with 👍 / 👎 to help improve future responses
4. Start fresh with **New Conversation**

## History

Previous questions are saved in your browser's local storage and shown in the Session History panel below the input area. Click any past question to reload it into the chat.
